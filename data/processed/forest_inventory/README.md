# Restricted data

This folder is intentionally empty in the public repository.

The forest inventory data (species-by-plot matrices) and sampling-unit coordinates of the Santa Catarina Forest and Floristic Inventory (IFFSC) are restricted and must be requested from SinFlor: <https://www.sinflor.com.br/>

Expected files:
- `first_cycle_species_by_plot.csv`
- `second_cycle_species_by_plot.csv`
